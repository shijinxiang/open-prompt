开放题记录库 · Windows 免安装版

1. 将整个压缩包解压到自己可读写的文件夹。
2. 双击 OpenQuestionStudio-0.3.1.exe 打开软件。
3. 首次使用为空题库，可以新建记录或导入已有备份。

运行环境：Windows 10 / 11，64 位。无需安装 Node.js，不需要登录，支持离线使用。

文本和截图保存在程序旁边的 data 文件夹，界面中的“打开 data 目录”可以直接打开。
字号设置和白天／黑夜模式保存在 data/settings.json，右上角齿轮可调整。
portable-mode.json 用于独立存储，请与程序一起保留。

记录以保存资料为主：决定性和非决定性核心考点分栏录入，各模型回复、截图、备注和结果独立保存。非决定性考点可留空，旧记录的新字段默认为空，原考点全文保留在决定性一栏。模型名称默认是豆包专家、GPT-5.6-Sol、Opus 4.6。
开启“二轮资料”后，可填写模型4、模型5的名称、回复、结果、达成性备注和截图。
还可记录五模型排序和排序说明。排序支持并列，例如“模型1 = 模型3 ＞ 模型2 ＞ 模型5 ＞ 模型4”。排序说明可分为总结和模型1至模型5六部分。
关闭二轮资料只隐藏这些字段，已填写的内容和截图仍保留，也会随完整备份导出。旧三模型记录默认关闭二轮资料。
不包含质检判断、审核结论、质检意见、专家返修备注或前三模型复核字段。
缺失资料只显示提醒，仍可正常保存；补齐后提醒自动消失。
每个模型回复旁的复制图标可一键复制完整 Markdown 原文，在原文和预览模式都能使用，无需选中文字。
排序说明不足300字、排序格式或段落不完整、模型名称重复时只提示，仍可保存。
截图支持选择文件、拖拽、在图片区粘贴，并可点击放大查看。
截图缩略图可以直接拖到文件夹、聊天窗口或其他支持文件拖放的应用，拖出的是原图副本，不影响题库原图。
每张截图旁的“复制图片”按钮可以将原尺寸图片复制到剪贴板，随后粘贴到文档或聊天窗口。题目附件录入区已移除，已有附件数据仍保留在备份中。

点击“导出备份”，可选择“全部记录”“未归档”“已归档”或“选择特定记录”，并查看对应记录数。默认导出全部记录，不受当前列表的分类和搜索条件影响；所选范围为空时不能导出。
选择特定记录时，未归档和已归档分组显示，可跨组勾选。按住鼠标上下拖动可连续多选，从已选记录开始拖动则连续取消；到列表上下边缘自动滚动。也支持全选、全选本组和清空选择。只导出所选记录的完整文字和截图。
每题显示完成百分比、进度条和缺失项数，完整题目显示100%与“资料完整”。鼠标悬停完成度可查看具体缺失项；可选字段不影响完成度，二轮资料开启时会计入额外模型和排序。
备份包含所选记录的完整文本、截图和保留的旧版资料。迁移到另一台电脑可导入备份，或关闭软件后复制整个文件夹（包括 data）。
专家填写助手1.3.8的“导入备份”可直接读取本软件导出的JSON，批量导入文字、两类考点、模型截图和排序。同编号记录跳过，不覆盖助手中已编辑的内容。请使用软件内“导出备份”，不要直接选择data/records.json。
更新程序时，只替换 exe 和说明文件，保留 data 文件夹。
可导入旧版完整备份。升级时会保留问题、回复、结果、备注、排序和截图；已取消字段直接丢弃，并在 data 中生成 records-before-v4.json 原始副本。
界面设置属于这台电脑的本地偏好，不随题库 JSON 备份导出。

发给别人时，使用干净的分享压缩包。不要把自己的 data 文件夹一起发送，除非准备分享这些记录和截图。


共享题库（新版存题软件 0.2.0 + 填写助手 1.5.0）

1. 启动新版存题软件，原项目可双击 Start-App.cmd。
2. 打开存题软件右上角“设置”，点击“复制共享题库连接码”。
3. 在新版填写助手顶部“与存题软件共用题库”中粘贴连接码，点击“连接共享题库”。
4. 连接成功后直接显示存题软件里的题目。任意一边修改、归档或恢复，另一边会自动更新，不必重复归档。
5. 共享使用时保持存题软件运行。本机接口只监听 127.0.0.1，题目和截图仍保存在原来的 data 文件夹。

共享模式中的自定义导入：
“导入备份”仍可导入存题软件 JSON、助手单条 JSON 和全部记录迁移 JSON。导入后直接加入共享主库。
存题软件 JSON 的同编号记录跳过，避免反复导入产生重复；助手单条备份始终作为新记录导入。助手全部记录迁移遇到相同编号时作为副本导入。
插件原有本机记录不会自动覆盖主库。需要合并时，点击“将插件原有本机记录加入共享题库”；同来源编号跳过，主库现有内容优先保留。若要保留旧插件中同编号的独立修改，可导出为单条备份后再自定义导入。
可点击“切回独立本机”继续使用原来的插件记录。两种模式的题号绑定分别保存，不会混用。

保存与恢复：
断开连接时会提示无法连接，不会悄悄切换到另一份题库。已经尝试保存但失败的修改会暂存在浏览器，恢复连接后重试；也可以先导出当前记录备份。
两边改不同字段会自动合并；同时改同一字段会提示选择保留哪一边，未选择前不会覆盖冲突字段。
明确提交成功后自动归档到这份共享题库；平台加载或提交失败不会据此归档。
删除共享记录也会删除存题软件中的同一记录，请留意删除确认。

安装和升级：
将新版“Chrome扩展”内所有文件复制覆盖到原安装文件夹，保持原路径，在 Chrome 扩展管理页重新加载，并刷新填写台、侧边栏和平台网页。
不要卸载旧扩展；保持原安装路径可沿用原有本机记录和设置。新版需增加本机 127.0.0.1 的访问权限，以连接存题软件。
更换电脑或换题库后，从对应存题软件重新复制连接码。连接码不随题目备份或迁移包导出。


0.2.1 大题库备份修复：导出按截图分段写入，导出窗口显示处理进度；超过512MB的完整JSON不再因字符串大小上限失败。大文件导入按题目分段读取并暂存截图，合并确认前不改题库记录；取消会清理暂存内容。导出失败时保留原目标文件，避免留下半份备份。


0.2.2 图片、题目TXT和界面调整：
点击模型截图后，可用滚轮以鼠标位置为中心缩放；放大后拖动查看。支持适应窗口、1:1原图、左右键切图和Esc关闭，不改原图。
左侧新增“导出题目 TXT”，原“导出备份”中也可切换格式。TXT只保存问题正文，题目之间空行分隔，不额外加入标题、编号、答案、考点或截图；支持全部、未归档、已归档和自选范围，空白问题跳过。
顶部左侧按钮可收起或展开分类侧栏、记录列表；列表与编辑区之间的分隔条可拖动调整宽度，布局会记住。窗口最小可缩至520×400，窄窗口的侧栏和列表按需展开，顶部标题与统计区已压缩。


0.2.3 多文件导入与目录记忆：
点击“导入备份”后，可按住Ctrl或Shift同时选择多个JSON备份。软件会先读取所有文件，再统一显示文件清单、新增数量和重复数量；确认后一次合并。题库已有编号优先保留，文件间重复时保留先读取文件的内容。任一文件损坏时整批停止，不会只导入前面的部分文件。
导入文件选择器会记住最近选定的文件夹，关闭软件后再打开也会保留。取消选择不会重置已记住的位置；已记住的文件夹被删除时，会使用它最近的现存上级目录。
