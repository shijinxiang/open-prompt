开放题记录库 0.3.0 · 安装与升级

首次安装：运行 OpenQuestionStudio-Setup-0.3.0.exe，安装后使用桌面或开始菜单入口。
若从原项目 release 文件夹运行安装器，会自动尝试沿用原项目的 data 题库。若没有自动找到，请在安装版“设置”中点击“关联已有题库并重启”，选择原来的 data 文件夹。

后续更新：在“设置 → 软件安装与更新”中检查、下载，然后点击“保存并安装更新”。安装前会保存资料，校验安装包，再自动覆盖程序并重启。
更新来源可填 GitHub 用户名/仓库名，或包含 update.json 的 HTTPS 目录。仓库尚未发布首个版本时会明确提示，不影响日常使用。

数据与程序分开：题库仍使用原目录，或使用当前用户 AppData 下的独立数据目录；不会放到安装程序自身目录。升级和卸载程序保留这些题库。若仍在沿用原项目的 data，请保留这个目录。
更新只读取公开版本信息并下载安装包，不上传题目、截图和本机认证配置。

没有准备远端地址时，可先正常安装使用。以后在设置中保存更新来源即可。
