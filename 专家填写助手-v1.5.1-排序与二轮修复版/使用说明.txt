专家填写助手 1.5.1：排序与二轮资料修复

1. 排序识别支持全角等号“＝”、全角大于号“＞”、实际模型名称及与模型序号混用，并保留并列名次。
2. “补填时同时同步五个模型的名次”改为插件独立选项。勾选或取消只影响网页导入，不再切换存题软件的“二轮资料”，模型4、模型5及排序资料保持原样。
3. 旧版因排序识别失败而留下的空名次，会依据原始来源信息自动恢复；已人工填写的名次保留。
4. 如果旧版已经折叠二轮资料，在存题软件重新打开“二轮资料”即可，原有内容仍在，无需重新填写。

升级：把本包“Chrome扩展”中的全部文件覆盖到原扩展安装目录，保持原路径；在Chrome扩展管理中重新加载，再刷新填写台、侧边栏和平台页面。不要卸载旧扩展，以保留原有本机记录。共享题库继续使用原连接配置。


专家填写助手 1.5.1（共享题库版）

共享题库（新版存题软件 0.2.0 + 填写助手 1.5.1）

1. 启动新版存题软件，原项目可双击 Start-App.cmd。
2. 打开存题软件右上角“设置”，点击“复制共享题库连接码”。
3. 在新版填写助手顶部“与存题软件共用题库”中粘贴连接码，点击“连接共享题库”。
4. 连接成功后直接显示存题软件里的题目。任意一边修改、归档或恢复，另一边会自动更新，不必重复归档。
5. 共享使用时保持存题软件运行。本机接口只监听 127.0.0.1，题目和截图仍保存在原来的 data 文件夹。

共享模式中的自定义导入：
“导入备份”仍可导入存题软件 JSON、助手单条 JSON 和全部记录迁移 JSON。导入后直接加入共享主库。
存题软件 JSON 的同编号记录跳过，避免反复导入产生重复；助手单条备份始终作为新记录导入。助手全部记录迁移遇到相同编号时作为副本导入。
插件原有本机记录不会自动覆盖主库。需要合并时，点击“将插件原有本机记录加入共享题库”；同来源编号跳过，主库现有内容优先保留。若要保留旧插件中同编号的独立修改，可导出为单条备份后再自定义导入。
可点击“切回独立本机”继续使用原来的插件记录。两种模式的题号绑定分别保存，不会混用。

保存与恢复：
断开连接时会提示无法连接，不会悄悄切换到另一份题库。已经尝试保存但失败的修改会暂存在浏览器，恢复连接后重试；也可以先导出当前记录备份。
两边改不同字段会自动合并；同时改同一字段会提示选择保留哪一边，未选择前不会覆盖冲突字段。
明确提交成功后自动归档到这份共享题库；平台加载或提交失败不会据此归档。
删除共享记录也会删除存题软件中的同一记录，请留意删除确认。

安装和升级：
将新版“Chrome扩展”内所有文件复制覆盖到原安装文件夹，保持原路径，在 Chrome 扩展管理页重新加载，并刷新填写台、侧边栏和平台网页。
不要卸载旧扩展；保持原安装路径可沿用原有本机记录和设置。新版需增加本机 127.0.0.1 的访问权限，以连接存题软件。
更换电脑或换题库后，从对应存题软件重新复制连接码。连接码不随题目备份或迁移包导出。


原有功能说明


请打开“先看这里-安装使用.html”查看完整说明。

旧版升级保留记录：
将新版“Chrome扩展”内全部文件覆盖到原安装文件夹，保持路径不变；
在 chrome://extensions 点击扩展的“重新加载”，再刷新填写台和平台网页。
不要卸载旧扩展，原有本机记录和图片会保留。
旧版本机题号绑定会迁入持久绑定；升级后仍建议核对首次选择的题号和记录。

固定绑定与切题：
首次开始导入时按完整题号固定记录，换标签页或重启浏览器也保留。切换题号时载入其绑定记录，平台左侧切题和切换平台标签页也会跟随。
手动在记录列表、当前记录下拉框或弹窗切换记录，会更换当前所选题号的已有绑定；未绑定题号在首次导入后固定。
导入中禁止同时更换该题号绑定，同一题号在不同标签页也不会同时串填。

已提交题号清理：
绑定记录归档、题号从平台列表移除时，会从可导入列表隐藏，旧地址栏和旧分配信息不会补回。
明确检测到提交成功或已提交/归档/完成状态时，绑定记录自动归档。提交失败、加载失败或暂时没有扫描结果不会因此归档。
仅从列表消失时先隐藏题号，保留原绑定和记录；以后重新出现仍匹配原记录。

覆盖范围：
不覆盖已有内容：保留网页已有值，继续补填空白项。
覆盖全部：可改写所有可编辑且记录中有内容的字段，包括以前填过的字段。
覆盖后半部分：仅允许改写模型4、模型5及排序区域；前半部分已有文字和图片保留，空白项仍可补填。
覆盖截图时替换对应模型原图，相同图片再次导入不会重复上传；未解锁字段仍等待下一次补填。
旧“允许覆盖”勾选状态自动迁移为覆盖全部，否则为不覆盖。此选项随记录备份和迁移保留。

归档与恢复：
右侧“我的记录”新增未归档、已归档两类，并分别显示数量。每条记录旁可归档或恢复；顶部当前记录旁也有同样入口。
归档当前记录后显示已归档分类，恢复后回到未归档；归档其他记录不切换当前记录。
正文、截图、排序、题号关联和补填报告保留，归档记录仍可查看、编辑和填写。
新记录默认未归档。从记录库JSON导入时沿用归档状态；助手单条JSON、整库迁移和ZIP迁移包均保留当前归档状态。
旧插件记录缺少归档字段时默认为未归档；已保留记录库来源归档信息时沿用该状态。
来源信息显示原JSON的历史状态；当前是否归档以插件分类和顶部标记为准。
多个填写台之间自动同步归档状态，其他窗口保存正文时不会意外撤销归档。
首次升级自动补充归档字段和列表摘要，旧记录的正文和图片原样保留。

保留的切换优化：
切换记录仅加载所选记录，未修改时不重复保存，不再等待所有平台页面扫描。
记录列表单独保存摘要，避免切换时读取全部正文和截图；截图缩略图按需解码。
选题先实时核对当前页面题号；新页面加载期间可继续选题或切换记录。
快速连续切换以最后一次选择为准，防止旧请求覆盖当前记录、题号或补填报告。
导入前和填写过程中继续核对题号。手动“刷新题号”会重新读取平台列表。
首次升级会在本机建立记录列表摘要；记录很多时，请等待首次加载完成。

从开放题记录库直接导入：
1. 记录库0.1.2增加非决定性核心考点，旧记录此字段默认留空，原考点全文保留在决定性一栏。
2. 记录库点击“导出备份”，选择全部、未归档或已归档范围，得到完整JSON。不要直接选择data/records.json，它不包含图片本体。
3. 助手点击“导入备份”，选择上述JSON，即可批量导入。相同来源编号跳过，不覆盖本机已编辑记录。
4. 核对来源信息中的实际模型名称，然后选择平台题号导入。模型1/2/3/4/5依次对应豆包/GPT/Claude/随机模型1/随机模型2栏。
两类考点分别保留原文和换行，模型回复的Markdown、达成性结果、备注和多张截图对应保存。
五模型有效排序支持并列；二轮关闭时保留名次但不自动同步，非法或不完整排序保留原文并提醒手动核对。
超过网页长度限制的字段不截断，导入后提示。截图异常会使整批导入停止，已存在记录保留。
记录名称、标签、归档状态、验收结果、原模型名称、题目附件和旧版资料保存在来源信息及备份中，不自动填写网页无对应的字段。
旧单条备份、全部记录JSON和整套迁移ZIP继续兼容。

首次安装：
将ZIP完整解压到固定文件夹，Chrome打开 chrome://extensions，开启开发者模式，
选择“加载已解压的扩展程序”，选中本包的“Chrome扩展”文件夹。
在Chrome拼图菜单固定“专家填写助手”，点击它打开完整填写台。

按题号导入：
1. 打开已登录的 https://aidp.bytedance.com 平台题目页。
2. 填写台点击“刷新题号”，列表显示平台左侧已加载的完整题号。
3. 在右侧选择或新建记录，可重命名、保留多条；再选择目标题号。
4. 题号已有标签页时复用该页，未打开时新建标签页，保留原页。
   等填写台显示定位完成后，点击“一键导入所选题号”。
5. 当前未出现或未解锁的字段待下次填写；平台解锁后再导入，跳过已填项。
6. 不同记录可分别导入不同题号；平台悬浮按钮使用当前题号已绑定的记录。
仅读取标题包含“AI数据服务平台”的上述域名标签页。
题号完整保留。同一题号在多个网页同时打开时，用“网页1、网页2”区分。
新标签页在后台加载；可点“前往该题”查看。
新页出现登录或加载提示时，请先在该页处理，然后刷新题号。
新题尚未在左侧加载时，请先在平台打开。本地演示仅用于查看。

侧边栏快捷操作：
打开侧边填写栏时，自动隐藏平台网页上的悬浮助手。
底部固定显示：题号选择框｜导入图片｜当前记录｜导入。
底部“当前记录02”表示正在使用第02条记录，与列表中的“当前”标记一致。
列表顶部“共4条”单独表示全部记录数量。
可在任意滚动位置选择题号、切换记录，点击右侧“导入”发送当前记录。
“导入图片”默认勾选，取消后跳过全部图片，文字与排序照常导入。
图片仍保留在记录和备份中，网页已有图片也保留；重新勾选可继续补填。
此全局开关会在本机记住，所有记录和导入入口共用；顶部有同名选项。
底部与顶部选择同步。定位中可继续选其他题号或记录；导入按钮等待当前定位完成后启用。

删除记录：
打开底部“当前记录”，每条记录的“重命名”旁有“删除”按钮。
删除前会确认记录名称，取消则保留原记录。顶部“删除”使用相同逻辑。
删除其他记录保留当前选择；删除当前记录切换到相邻记录。
删除最后一条后自动准备一条新空白记录。编号和总数会更新。
删除本机记录及截图、题号关联和补填报告，原平台网页内容保留。
需要恢复时可导入之前导出的备份；删除后新的迁移包不再包含该记录。

图片粘贴：
先点击对应模型的“回复截图”虚线框，再按Ctrl+V；
也可按Win+V打开Windows剪贴板历史，选择图片项。
支持多张图片、预览、删除，也可拖入或选择图片文件。

图片详情：
点击已添加图片的缩略图或文件名，打开原图详情。
滚轮或加减按钮缩放，放大后拖动；可选“1:1原图”或“适应窗口”。
双击切换原图视图；多张图片可用左右按钮或键盘方向键切换。
右上角×、窗口外部或Esc关闭；预览不压缩、不修改原图片。
取消“导入图片”时仍可查看本机图片；切换记录会关闭原记录预览。

换电脑方式一：
点击“导出整套迁移包”。下载的ZIP包含程序、全部记录和图片。
新电脑解压并加载里面的“Chrome扩展”，首次打开填写台自动恢复记录。

换电脑方式二：
1. 点击“连接随身文件夹”，选择本工具原安装文件夹或里面的“Chrome扩展”。
2. 修改、导入的记录和图片会自动同步到Chrome扩展/portable-records.json。
3. 复制或打包前点“立即同步”，等显示“已同步到…”再复制整个文件夹。
4. 新电脑加载里面的“Chrome扩展”，打开填写台自动恢复记录。
5. 新电脑上的后续修改若需继续回写，请再连接一次本机文件夹。
仅复制未同步的原程序文件夹，不会带走Chrome本机存储里的新记录。
迁移后需重新登录平台、选择题号；网页关联及已粘贴状态不迁移。

题目辅助判断及其不认同备注、达成性辅助判断、考点质检均已从填写台移除。
工具不自动提交，填写后请在平台核对并暂存。题号绑定属于本机平台使用状态，不随跨电脑迁移包传递。
已通过模拟平台新建标签页、防错填、补填与记录迁移测试；未访问你的真实登录账号。
