1.5.1 排序识别与二轮开关修复

支持全角等号、实际模型名称及混合写法，正确识别并列排序。旧版未识别而留下的空名次会根据原始来源自动恢复，人工名次保留。

插件“同步五个模型的名次”现在是独立选项，不再改变存题软件的“二轮资料”开关。已经被旧版折叠的资料可在存题软件中重新开启，原文仍在，无需重填。

升级请将全部扩展文件覆盖到原安装目录，重新加载扩展，并刷新填写台与平台页面。不要卸载原扩展。

1.5.0 与存题软件共用一个数据库

  1. 启动新版存题软件 0.2.0，在“设置”中复制共享题库连接码。
  2. 在填写助手顶部粘贴连接码，点击“连接共享题库”。共享时保持存题软件运行。
  3. 任意一边归档、恢复或修改都会自动同步。提交成功后的自动归档同样写入这份题库，无需两边分别操作。

“导入备份”继续支持自定义JSON，导入后直接加入共享题库。需要时可点击“将插件原有本机记录加入共享题库”，同来源编号跳过。也可切回独立本机模式继续使用原记录。

断开连接时明确提示，并暂存未保存修改，重新连接后重试。同一字段有冲突时可选择保留哪边。连接码保存在本机扩展设置，不会随题目备份或整套迁移包导出。

升级请覆盖原安装目录中的全部文件、重新加载扩展，并刷新填写台和平台网页；不要卸载旧扩展。新版需要访问本机127.0.0.1，以连接存题软件。

1.4.0 固定绑定、已提交题号清理和覆盖范围

  1. 按完整题号固定绑定。首次开始导入时固定该题号使用的记录，换标签页或重开浏览器仍保留。选择其他题号时，会自动载入其绑定记录；在平台左侧切题或切换平台标签页时，填写台也会跟随。手动切换记录才会更换已有绑定，弹窗记录选择也遵循同一规则。
  2. 自动移除已完成题号。绑定记录已归档时，对应题号隐藏；平台题目列表已经移除的题号不再被旧地址栏补回。明确看到提交成功或已提交/归档/完成状态时，绑定记录会归档。加载失败或提交失败不会据此归档。
  3. 覆盖范围分为三档。不覆盖已有内容、覆盖全部、覆盖后半部分（模型4及以后）。后半部分包括模型4、模型5、其名称/回复/结果/备注/截图和排序说明、名次；前半部分已有内容保留，空白项可补填。空白记录字段不主动清空网页，隐藏或锁定字段仍等待解锁。

覆盖模式对以前已填写过的字段同样生效；相同图片不会重复上传，替换截图时先核对并移除对应区域的旧图。若网页未接受操作，会逐项显示错误，填写后仍需在平台核对和暂存。

旧版“允许覆盖”已勾选时自动对应“覆盖全部”，未勾选对应“不覆盖已有内容”。覆盖范围随单条备份和整套迁移包保留。本机题号绑定保存在浏览器扩展存储中，不随跨电脑迁移包转移；新电脑重新选择题号并首次导入后绑定。

升级后请重新加载扩展，并刷新全部填写台、侧边栏和平台网页，使页面观察器与新版填写逻辑一起生效。

1.3.9 归档与恢复

右侧“我的记录”新增未归档 / 已归档分类和各自的记录数。每条记录旁可点“归档”或“恢复”，顶部当前记录旁也有相同入口。归档当前记录后会切到已归档分类，恢复后回到未归档分类；归档其他记录时保持当前记录选择。

归档保留正文、截图、排序、题号关联和补填报告，可随时查看、编辑或恢复。新记录默认为未归档。从记录库JSON导入时沿用其归档状态；助手单条备份、全部记录JSON和ZIP迁移包均保留当前归档状态。来源信息中的归档状态记录原JSON内容，当前状态以插件分类和顶部标记为准。

旧插件记录自动升级：没有归档字段时按未归档处理；已有记录库来源归档信息时沿用来源状态。多个填写台同时打开时归档状态自动同步，普通内容保存保留数据库中的归档状态。

1.3.8 直接导入开放题记录库

  1. 在新版记录库中分别填写决定性和非决定性核心考点。旧记录原考点保留在决定性一栏，新增非决定性字段默认为空。
  2. 记录库点击“导出备份”，可选择全部、未归档或已归档记录。请使用导出的完整JSON；data/records.json没有内嵌截图。
  3. 本助手点击“导入备份”，直接选择这个JSON，一次读取全部记录、模型回复、结果、备注、截图和排序。相同来源编号跳过，保留助手内的人工修改。
  4. 核对来源信息中的实际模型名称，再选择目标题号并执行导入。五模型按记录库的模型1至5顺序对应平台的五个回复栏；前三个模型的实际名称不自动改写为平台预设名称。

标题作为记录名称；两类考点分别填写两栏，原文与换行保留。有效五模型排序含并列时自动换成对应名次；二轮资料关闭时保留名次但不自动启用同步，格式不完整时保留原文并显示提醒。字段超过网页限制时完整保存并提示，不截断。

标签、归档状态、验收结果、原始模型名称、题目附件及旧版历史保留在“来源信息”和助手备份中，没有对应的网页字段时不发送。已有单条JSON、全部记录迁移和整套ZIP导出仍可使用。

1.3.7 切换性能优化

切换记录只加载选中的记录，不再等待全部平台标签页扫描；未修改的记录不重复写入，列表摘要单独保存，截图缩略图按需加载。首次升级会建立摘要，记录很多时请等待首次加载完成。

题号定位期间可继续选择其他题号或记录，以最后一次选择为准；旧请求不会覆盖新选择或报告。导入按钮等待当前定位完成后启用，导入前与填写过程中继续核对题号。“刷新题号”可立即重新扫描平台列表。

旧版升级，不丢记录

把新版“Chrome扩展”内的全部文件复制覆盖到原安装文件夹，保持原路径；再在 chrome://extensions 点击本扩展的“重新加载”。刷新填写台和原网页。不要卸载旧扩展。旧版记录和备份继续可用。

首次安装与新电脑安装

  1. 将ZIP全部解压到固定文件夹。
  2. Chrome 地址栏打开 chrome://extensions，开启右上角“开发者模式”。
  3. 点击“加载已解压的扩展程序”，选择里面的 Chrome扩展 文件夹（直接包含manifest.json）。
  4. 点击Chrome右上角拼图图标，固定“专家填写助手”，点击扩展 → 打开完整填写台。

如果这个文件夹来自带记录的迁移包，新电脑第一次打开填写台会自动恢复全部记录和截图；本机已有记录时，点击“导入文件夹记录”合并，保留原记录。

图片直接粘贴

  1. 复制一张截图或图片。
  2. 在对应模型的“回复截图”区点击蓝色虚线框，让该框获得焦点。
  3. 按 Ctrl+V；或按 Win+V 打开Windows剪贴板历史，选择图片项。图片会加入这个模型并显示预览，可连续粘贴多张。

Win+V历史功能需Windows已开启；本工具接收系统产生的图片粘贴事件。复制图片地址、文本路径或纯文字不会作为图片导入。仍支持选择文件和拖入图片，每张最大20MB。

点击图片查看详细内容

在模型的回复截图列表中，点击缩略图或文件名，即可打开原图详情。顶部显示文件名、像素尺寸和文件大小；默认完整显示图片。

  1. 使用鼠标滚轮或＋ / −缩放图片，放大后按住鼠标拖动，可查看长截图中的细节。
  2. 1:1原图按原始像素显示；适应窗口恢复完整视图。双击图片可在两种视图间切换。
  3. 同一个模型有多张截图时，可使用上一张/下一张按钮或键盘← / →切换。
  4. 点击右上角×、窗口外部或按Esc关闭。键盘＋ / −缩放，0适应窗口，1显示原图。

侧边栏和完整填写台均可预览。预览不会修改、压缩原图片，也不影响导入和迁移；取消勾选“导入图片”时仍可查看本机图片。切换记录时会关闭原记录的预览。

换电脑方式一：直接导出完整迁移ZIP

  1. 填写台点击导出整套迁移包。
  2. 生成的ZIP包含程序、全部记录、记录名称、字段内容、排序、截图原文件，不只导出当前一条记录。
  3. 把ZIP复制到另一台电脑，解压并按上面的步骤加载“Chrome扩展”。
  4. 首次打开填写台会恢复记录。登录原网站后，为记录重新选择目标网页。

以后再换电脑，请重新导出一个最新迁移包。此方式无需选择可写文件夹。

换电脑方式二：打包原来的整个文件夹

  1. 填写台点击连接随身文件夹，在Chrome弹出的文件夹选择器中，选择本工具最外层的原文件夹，或里面已安装的Chrome扩展文件夹。只做一次连接即可。
  2. 记录、改名、图片、导入的记录等修改，之后会自动写入 Chrome扩展/portable-records.json。
  3. 准备打包前点击立即同步 / 继续同步，等待显示已同步到…。再把整个最外层文件夹打包或复制到另一台电脑。
  4. 新电脑解压并加载里面的“Chrome扩展”，打开填写台自动恢复记录。
  5. 要让新电脑上的后续修改也回写这个文件夹，请在新电脑再点一次“连接随身文件夹”。文件夹写入授权不会跨电脑转移。

普通Chrome本机存储不在程序文件夹里。请至少完成一次文件夹同步，或使用“导出整套迁移包”；仅复制未同步的原程序文件夹不会带走本机新增记录。

记录仍会先保存在本机。若提示需要授权、未同步或文件夹不可用，请点击继续同步或重新连接；也可直接导出迁移包。复制文件夹前等同步完成，之后再关闭填写台。不要手工修改portable-records.json。

只识别平台，按题号导入

插件只读取 https://aidp.bytedance.com 中标题包含 AI数据服务平台 的标签页。其他网站、同名的其他网站、本地HTML都不会读取或填写。

  1. 打开平台的题目页。填写台点击刷新题号，下拉列表显示类似 7696441604618424073 的完整题号。
  2. 列表汇总平台各标签页的当前题号与左侧已加载的题号。题号全程按文本保留，不会截断或四舍五入；同一题号在多个网页都打开时，会加“网页1、网页2”区分。
  3. 选择记录，再选择目标题号。该题号已有标签页时直接使用对应页面；尚未打开时，会新建标签页打开题目，保留原页题号和未保存内容。新页面在后台加载，等待填写台显示定位完成，再导入；也可点击前往该题查看。
  4. 点击一键导入所选题号。工具再次核对当前题号与网页地址，匹配后才填写。若新标签页出现登录、加载或平台提示，请先在该页处理，再刷新题号。

记录A可导入题号A，记录B可导入题号B；每个题号对应的标签页分别保存补填绑定和状态；连续选择同一题号会复用其已打开页面。平台悬浮补填按钮使用当前题号已绑定的记录。新题号尚未绑定时，会提示先选择记录，避免沿用上一题的记录。

未出现、折叠或锁定的字段留待下次；在平台完成审核和确认、解锁后继续补填，已填字段跳过。新领取或尚未加载在左侧的题目，请先在平台打开或加载，再刷新题号。旧版本机已有题号绑定会迁入持久绑定，升级后请核对当前题号和记录，正文与图片保留。

侧边栏底部快捷操作

点击扩展的“侧边填写”打开侧边栏后，平台网页左下角或右下角的悬浮助手会自动隐藏。侧边栏和窄窗口底部始终显示 题号选择框｜导入图片｜当前记录｜导入，滚动到任意填写区域都可以使用。

  1. 左侧题号框与顶部“目标题号”同步；未打开的有效题号仍会新建标签页，保留原页面。
  2. 题号框旁的“导入图片”默认勾选。取消后，本次导入跳过全部图片，文字和排序照常发送；记录中的图片和已上传到网页的图片不会删除，备份仍包含截图。重新勾选后可继续补填图片。此全局选择会在本机记住，适用于所有记录，以及顶部、底部、弹窗和悬浮补填入口。
  3. 点击中间“当前记录”选择需要的记录；底部显示当前编号，例如“当前记录02”，与列表中标记“当前”的记录一致；列表顶部“共4条”单独表示总数。每条记录保留自己的目标题号。
  4. 点击右侧“导入”，将当前记录导入所选题号。此按钮与顶部一键导入相同，解锁后可再次点击，跳过已填字段。

删除不再需要的记录

打开底部“当前记录”，每条记录的“重命名”旁新增删除按钮。点击后会显示记录名称并要求确认，取消后保留原记录。顶部“删除”按钮也使用相同逻辑。

删除会移除这条本机记录及其截图、题号关联和补填报告，原平台网页中已填写的文字、图片不会删除。删除其他记录时，当前记录保持不变；删除当前记录时，自动切换到相邻记录；删除最后一条后，自动准备一条新空白记录。编号和总数会随列表更新。

需要日后恢复时，请先导出备份。删除后导出的迁移包和同步文件夹会排除已删除记录；此前保存的旧备份仍可手动导入恢复。

迁移内容与使用范围

文字、截图、记录名称、排序和填写选项一起迁移；登录状态、浏览器题号列表、标签页关联、已经粘贴过的状态由各电脑的浏览器管理，需要在新电脑重新登录、选择网页并核对。

“导出备份”保留为单条记录JSON；“导入备份”兼容旧版单条记录，也可选择迁移包里的portable-records.json导入全部记录。

工具不会自动提交、代替原网页的审核或保证图片已上传至服务器，补填后请核对并暂存。本地演示只用于查看，插件不再对本地HTML执行补填。

数据只保存在本机和你选择的文件夹，不上传云端。迁移包含你的全部记录和截图。Windows剪贴板历史及Chrome文件夹选择器需在你的电脑上使用；制作环境以模拟平台页面验证题号识别、新标签页定位和防错填，以及图片粘贴事件与迁移；未访问你的登录账号，真实平台的新页面加载、保存、上传仍需核对。
